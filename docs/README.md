# Repository compliance

This tool checks GitHub repositories against team standards and writes one Markdown report. You choose the repositories and any rules they are exempt from.

Run it locally or through GitHub Actions. It reports findings; it does not change the repositories.

- [Quick start](getting-started.md): install, configure, and run.
- [Contributing](development.md): code style, tests, and quality checks.
- [Adding and removing rules](rules.md): rule structure, prompts, and registration.
- [Architecture](architecture.md): a diagram of how a run works.
- [Package guide](package-layout.md): where code belongs and how modules depend on each other.
